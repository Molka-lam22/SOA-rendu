Qu’est-ce qu’un web service ?

Deux applications écrites dans des technologies différentes échangent des données sur le réseau grâce à une API. Aucune n’a besoin de savoir comment l’autre est construite.

Trois familles de web services

SOAP

Le standard « étendu » et lourd : des messages XML avec des contrats stricts.

REST API

Des ressources accessibles par des URL et des verbes HTTP, échangeant généralement du JSON.

GraphQL

Un seul endpoint et un langage de requête : le client choisit les champs exacts.
